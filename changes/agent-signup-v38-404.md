### IMPROVED

- The Discount code sign-up asks for the name in three boxes, First, Middle and Last, all
  required, in capitals. Space moves to the next box and a pasted full name fills all three.
- "Do you already have a Discount code?" No now goes straight to the review. Yes opens the code
  box, which adds the hyphen by itself (AAN132 becomes AAN-132).
- The review shows only the first letters the new code will start with. The whole code appears
  on the finished screen, and the sign-up never shows anyone else's code.
- New Discount codes are the agent's initials, a hyphen and the next number after the last code
  made: ABC-123, then XYZ-124. This holds for sign-ups, Create agent and the agent import, and two
  sign-ups at the same moment never get the same code.
- Start over sits on the first question only, even when the form is empty, and Back takes its
  place after that. With answers it asks first; on an empty form it says there is nothing to clear;
  on the finished screen it opens a new form at once, as does "Start again".
- The finished screen shows the Admission form's green tick mark.

### FIXED

- No to "Do you already have a Discount code?" no longer shows the code box as optional.
- The Discount code box keeps two-letter codes (JD-123) and numbers past 999 as typed, and leaves
  codes of other shapes, such as Promo codes that start with four letters, unchanged.
