### IMPROVED

- Import agents needs only each agent's three names and their ABC-123 code. Mobile, WhatsApp and Email may be left empty, and an agent imported without a mobile shows "No mobile" on the Agents screen. A row with one or two names, or with a missing or wrongly shaped code, is refused with its reason. Everywhere else an agent is made still asks for a mobile.
- An agent imported with only their names and code can claim it on the Discount code page: they answer Yes to "Do you already have a Discount code?" and type their code, and their three names identify them. The mobile and WhatsApp they type are stored when the school confirms their email.
