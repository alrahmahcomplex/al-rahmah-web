### NEW

- On Register Students, the Discount code box has an arrow that lists every code that works today, with a search box on top. Promo codes come first, then agent codes, each A to Z. Each agent code shows the agent's name, and each Promo code shows what it takes off. Search finds a code or a name.
- As you type a code, the rest of the first matching code shows faintly after your letters. Press Tab or → to take it, or keep typing.
