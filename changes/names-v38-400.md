### NEW

- Names can now be saved the new way: the student's own name, then the father's first, middle and last names, all required and stored in capitals. The student's full name is the student's name with the father's first and last names; the father's full name keeps all three. The new Admission form and Register students screens will use this.
- A custodian's name is saved as first, middle and last names, in capitals. Who brought the students needs at least two names.

### IMPROVED

- Students added by import are saved with their names and their parent or guardian's names in capitals. Students already on file keep their names as they are.
- When a father's name on file has no middle name and a newly entered one has three names with the same first and last name, staff are asked whether it is the same father. Before, the names counted as different and needed a Sibling request.
