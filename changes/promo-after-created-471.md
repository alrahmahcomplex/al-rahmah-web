### IMPROVED

- A Promo code now gives its discount only to applications sent after the code was created, from the Admission form or the Register students form. An application that carried the code earlier, typed before it was announced, never gets the discount, even if staff add the code later. Its Referral code panel says "No discount: application sent before the Promo code was created".
- Imported student records keep the discount whenever they were imported, before or after the code was created. Creating a Promo code now lowers only the unpaid fees of imported records that already carry it.
- The fee counts on the Promo codes page, the list of families a change would move, and the student export follow the same rule.
