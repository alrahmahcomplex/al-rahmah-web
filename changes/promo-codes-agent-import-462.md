### NEW

- A Promo code can now be in any format: letters, numbers and symbols such as `-` and `$`, in any mix, up to 20 characters (SAVE10, AS-135, $AVE). It can't be in an agent's ABC-123 shape. Parents type it into the Admission form's Discount code box as it is.

### IMPROVED

- An agent's Discount code is always 3 letters, a hyphen and 3 numbers (ABC-123). Wherever one is typed (the Discount code page, Create agent and Recreate), the hyphen goes in by itself after the third letter, and a hyphen typed again is ignored. A new code always gets three letters, even for a name with fewer than three words, and always three numbers.
