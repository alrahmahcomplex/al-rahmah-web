### NEW

- Register students takes a whole family in one save: up to 8 students, then their custodians, who brought them, the Discount code and the fees. Either everyone is registered or no one is.
- Each student's name is their own name plus the father's three names. Students with the same father's name are asked about as siblings. A typing mistake in a father's name is fixed in one step, and different fathers' names send a Sibling request to the Admissions Manager.
- The custodian's phone number is checked against families on file. A child on file with the same father's name is offered as a sibling.
- The fee step shows each student's School fee and the sibling discount before you register.
- If a save fails, the answers stay in the tab, so nothing has to be typed again.

### IMPROVED

- Register students opens from Home in the new look, with a Home button back. "Back to Check-in" on an application now reads "Back to Home".
- Register students needs permission to view school-fee payments, as well as to create applicants and record visits.
